A compact, deterministic Python chess engine using 0x88 move generation, iterative deepening, alpha-beta/PVS search, a transposition table, and quiescence search.

## Run it

```sh
python3 -P -s main.py
```

The packed entrypoint is self-contained and uses only Python's standard library. It reads the Make.fun game service URL from `MAKEFUN_ENV_URL`.
